
# Sample Flask Application

This is the sample Python application used to test the Intelligent DevSecOps Pipeline.

## Requirements

- Python 3.10 or later
- pip

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the application

```bash
python app.py
```

The application will run locally at:

http://127.0.0.1:5000

## Available Endpoints

| Endpoint | Purpose |
|---|---|
| `/` | Welcome message |
| `/health` | Application health status |
